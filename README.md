# raibitScoreboard — 근전도 기록 측정

선수 한 명이 SpikerBox에 연결된 근전도 센서로 5초 동안 힘껏 쥐고, 가장 센 순간의 점수로 기록을 세우는 펀치머신식 Electron 앱입니다. 명예의 전당(상위 5개)을 관리합니다.
Windows / macOS 둘 다 지원하고, 인터넷 없이 동작합니다(Do Hyeon 글꼴 포함).

## 하드웨어 구성

```
근전도 센서 → SpikerBox ──USB(바이너리 파형)──┐
                                               ├→ 노트북 (이 앱)
START 버튼  → 아두이노  ──USB(텍스트, 9600)───┘
```

- **SpikerBox Pro (HID)**: 시리얼 포트가 아니라 USB HID(벤더 0x2E73)로 잡히는 기기는 자동으로 찾아 엽니다(포트 탐색 불필요). 다른 프로그램(Spike Recorder 등)이 쓰는 중이면 열리지 않습니다.
- **SpikerBox**: 원시 파형을 앱이 직접 해석합니다. 근전도 센서는 기본 채널 1에 꽂습니다(관리자 화면에서 1/2 선택).
- **START 아두이노**: 버튼 전용입니다. 스케치는 `arduino/start_button/start_button.ino` (버튼 핀 2번 ↔ GND, 9600 baud). 누를 때 `START`, 1초마다 `ALIVE`를 보냅니다.
- USB 시리얼 포트를 전부 자동으로 열고 **무엇이 오는지로** 역할을 정합니다. 포트 이름은 신경 쓰지 않아도 되고, 블루투스 포트는 열지 않습니다.
  1. SpikerBox 탐색: 222222 → 500000 baud로 열어 `b:;`를 보내고 기기 응답(HWT)이나 정상 프레임이 오는지 1초 본다.
  2. 아니면 9600 baud 텍스트 포트(START 아두이노)로 연다.
  - 자동 판별이 틀리면 관리자 화면의 포트별 드롭다운(자동 / SpikerBox / START)으로 고정합니다.
  - 관리자 화면의 **2페이지 · 진단** 버튼을 누르면 원시 파형, 100 ms RMS, 원시값·해상도·초당 샘플, 포트·USB 장치 상태, 최근 로그를 실시간으로 볼 수 있습니다.
  - 같은 화면의 **녹화**를 켜면 100 ms 구간마다 RMS·세기·점수가 데이터 폴더의 `recordings/rec-<시각>.csv` 에, 원시값이 같은 이름의 `.raw` (int16) 에 저장됩니다. 숫자키 0~4 (없음·쉼·약하게·중간·최대) 로 지금 하는 동작을 표시하면 CSV 와 그래프 아래 띠에 남습니다. **폴더 열기**로 파일을 찾을 수 있습니다.
- 케이블이 빠졌다 다시 꽂히면 2초 안에 자동으로 다시 엽니다.

## 실행

```bash
npm install
npm start          # 실제 장치와 함께 (전체화면 kiosk)
npm run sim        # 장치 없이 시뮬레이션 (= electron . --sim)
npm test           # 경기 로직·명예의 전당·저장·SpikerBox 파서·신호 처리 단위 테스트
```

### 전체화면 / 창 모드

- `F11` 키(macOS는 `Control + Cmd + F`도 가능) 또는 관리자 화면 오른쪽 위 "창 모드로 보기 / 전체화면으로 보기" 버튼으로 바꿉니다.
- 마지막으로 고른 방식이 저장돼서 다음에 켤 때도 그대로 시작합니다(`settings.json`의 `"fullscreen"`).
- 실행 인자로 한 번만 정할 수도 있습니다: `--windowed`(창 모드), `--fullscreen`(전체화면).

```bash
npx electron . --sim --windowed
```

- 화면은 1440×900 기준 디자인을 비율 유지한 채 꽉 차게 확대·축소합니다(남는 부분은 배경색).
- 종료: macOS `Cmd+Q`, Windows `Alt+F4`, 또는 관리자 화면의 "앱 종료".
- 앱은 하나만 실행됩니다(두 개가 시리얼 포트를 서로 뺏지 않게. Spike Recorder 같은 프로그램도 같은 포트를 동시에 열 수 없으니 행사 중에는 끈다).

## 빌드

```bash
npm run build:win   # dist/ 에 Windows용 portable .exe 와 설치형 setup .exe
npm run build:mac   # dist/ 에 macOS용 .dmg (Apple Silicon / Intel 각각)
```

- 두 빌드 모두 macOS에서 만들 수 있습니다. Windows에서는 `build:win`만 됩니다.
- serialport는 미리 빌드된 바이너리(N-API)를 쓰므로 Python, Visual Studio, Xcode 같은 컴파일 도구가 필요 없습니다.
- 코드 서명은 하지 않았습니다. macOS에서 처음 열 때 "확인되지 않은 개발자" 경고가 나오면 앱을 **우클릭 → 열기**로 엽니다. Windows SmartScreen 경고가 나오면 "추가 정보 → 실행"을 누릅니다.

## 측정 흐름

```
IDLE(대기) --START--> MEASURING(5초 측정) --50칸 완료 또는 8초--> RESULT
RESULT --START--> MEASURING
```

- START(물리 버튼 / 관리자 "측정 시작")를 누르면 점수를 0으로 비우고 측정을 시작합니다. 측정 중의 START는 무시합니다.
- 측정(5초): 100 ms마다 한 칸, 50칸을 모읍니다.
  - **한 칸의 값** = SpikerBox 신호에서 전원 잡음(60 Hz와 배수)과 80 Hz 아래를 거른 뒤 그 100 ms 동안의 RMS − 휴식 RMS(영점) − 여유(1.5) = **세기** → **점수표**로 점수.
  - **점수**: 세기를 **기준 힘**(운영자가 최대로 쥔 힘)의 몇 % 인지로 바꾼 뒤, 곡선(직선·완만·보통·가파름 또는 직접 고친 점)으로 점수를 냅니다. 기본: 기준 힘 = 7000점, 보통 곡선(높은 점수일수록 올리기 어려움).
  - 큰 숫자와 레벨 미터는 **현재 힘**을 부드럽게 보여주고, `측정 n / 50 · 최고 x`로 지금까지의 최댓값을 함께 보여줍니다.
- 안전장치: START 후 8초가 지나도 50칸이 안 차면(SpikerBox 끊김 등) 받은 것까지의 최댓값으로 확정합니다.
- 결과: 50칸 중 **최댓값**이 최종 기록입니다. 승패는 없습니다.
- 결과 화면에는 명예의 전당에 들어갔으면 `명예의 전당 n위!`, 그리고 5위 밖이어도 항상 `지금까지 N개 기록 중 M위`가 나옵니다. 이를 위해 모든 측정 기록(0점 제외)을 `records.json`에 남깁니다.

## 자동 보정 · 점수

새 노트북이나 새 장소에서는 관리자 **3페이지 · 설정**의 **자동 보정 (12초)** 을 누릅니다.

1. 5초 동안 힘을 빼고 가만히 있습니다. 이 노트북·장소의 잡음을 재서 전원 주파수(50/60 Hz), 영점, 여유를 정합니다.
2. 신호가 나오면 4초 동안 최대로 꽉 쥡니다. 힘이 잘 보이는 채널과 고역 통과를 고르고, 그 최대 힘을 **기준 힘**으로 잡습니다.
3. 바뀌는 값과 경고를 보고 **적용**을 누르면 저장됩니다. 마음에 안 들면 **다시** 또는 **닫기**.

- **잡음만 (5초)**: 쉬는 동안만 재서 전원·영점·여유만 다시 맞춥니다. 설정을 가져온 뒤나 장소의 잡음이 바뀌었을 때 씁니다.
- **최대 힘 재기**: 기준 힘만 다시 잽니다.
- 점수 곡선은 버튼으로 고르거나, 그래프의 점을 끌어서, 또는 **세부 점 고치기**에서 숫자로 고칩니다. **설정 저장**을 눌러야 반영됩니다.
- 신호 칸(채널·전원·영점·여유·고역)은 손으로도 고칠 수 있습니다. **내보내기/가져오기**로 다른 노트북에 옮길 수 있습니다(영점은 옮기지 않음).

## 도전자 이름 · 축하

- 관중 화면에서 **Control + F** (Windows: Ctrl + F)로 다음 도전자 이름을 넣습니다.
- **이름 받고 시작**(관리자 1·3페이지)이 켜져 있으면, 이름 없이 START 를 눌렀을 때 입력창이 뜨고 Enter 로 바로 시작합니다(비우고 Enter 면 이름 없이). 끄면 예전처럼 바로 시작합니다.
- 이름 받기가 켜진 상태에서 명예의 전당(5위 안)에 들면 폭죽과 함께 "OOO님 N위 축하드립니다!"가 뜹니다.

## 명예의 전당

- 측정이 끝나는 순간 기록(0점 제외)이 전체 기록에 자동 저장되고, 명예의 전당은 그중 상위 5개입니다.
- 새 기록 이름은 `ㅇㅇㅇ`이고 날짜·시간이 함께 저장됩니다. 같은 점수면 먼저 세운 기록이 위입니다.
- 관리자는 어떤 기록이든 이름·점수를 고치거나 지울 수 있습니다(아래 관리자 화면).

## 관리자 화면

| 동작 | Windows | macOS |
|---|---|---|
| 열기 / 닫기 | `Ctrl + D` | `Control + D` (Cmd 아님) |
| 닫기 | `Esc` 또는 "스코어보드로 돌아가기" | 같음 |

- 기록 카드는 처음에 명예의 전당(상위 5개)을 보여 줍니다. **전체 기록 보기**를 누르면 모든 기록이 점수순으로 나옵니다(스크롤).
- 이름·점수를 고친 뒤 **변경 저장**(또는 Enter). 빈 이름은 `ㅇㅇㅇ`, 점수는 0~9999. 점수를 고치면 순위가 다시 매겨집니다.
- 줄 끝의 **✕**로 기록 하나를 지웁니다(확인 창).
- **기록 전체 삭제**: 모든 기록을 비우고 대기 화면으로 돌아갑니다. 지우기 전 파일은 데이터 폴더에 `*.bak-<시각>`으로 남습니다. 축제 시작 전에 테스트 기록을 지울 때 씁니다.
- "측정 시작" = START 버튼과 동일. "측정 중지 · 기록하지 않음"은 측정 중일 때만 눌리고 아무것도 저장하지 않습니다.
- 장치 연결 카드: SpikerBox(포트, 기기 종류, 채널 수, 초당 프레임, 현재 RMS)와 START 버튼(포트, 마지막 START), "포트 다시 연결", 포트별 역할 고정.
- 보정 설정: 영점 잡기, 시뮬레이션 켜기/끄기, 3페이지(자동 보정·점수) 바로 가기.

## 시뮬레이션 모드

`npm run sim`(또는 `--sim`)으로 실행하거나 관리자 화면에서 "시뮬레이션"을 켭니다. 가짜 SpikerBox가 실제 장치처럼 바이트 스트림(10 kHz)을 만들어 실제 파서와 RMS 경로를 그대로 거칩니다. 시연용으로 보정계수 1에서 4000~7500점(게이지 레벨 6~11) 정도가 나오고, A를 누를 때마다 세기가 무작위로 달라집니다.

| 키 | 동작 |
|---|---|
| `S` | START |
| `A` (누르는 동안) | 근육 수축 (신호가 서서히 커지고, 떼면 작아짐) |

한글 입력 상태에서도 동작합니다. 관리자 화면이 열려 있을 때는 동작하지 않습니다.

## 설정 파일 위치

| OS | 폴더 |
|---|---|
| Windows | `%APPDATA%\raibitScoreboard\` (보통 `C:\Users\<사용자>\AppData\Roaming\raibitScoreboard\`) |
| macOS | `~/Library/Application Support/raibitScoreboard/` |

- `settings.json`: 앱을 끈 상태에서 직접 고쳐도 되고, 관리자 화면에서 고쳐도 됩니다.

  ```json
  {
    "calibration": 1.0,
    "emg": { "channel": 1, "restRms": 0 },
    "portRoles": {},
    "fullscreen": true
  }
  ```

  `portRoles`는 `{ "<포트 경로>": "spikerbox" | "start" }`. 없는 포트는 자동 판별합니다. v1 설정(`calibration: {p1, p2}`)은 p1 값으로 이어받습니다.

- `records.json`: 모든 측정 기록(`id, name, score, at`). 명예의 전당은 여기서 상위 5개를 계산합니다. v2.0.x의 `hall-of-fame.json`·`score-history.json`이 있으면 처음 실행할 때 한 번 옮기고, 옛 파일은 그대로 둡니다.
- 저장은 임시 파일(`*.tmp`)에 쓴 뒤 이름을 바꾸는 방식이라, 저장 도중 꺼져도 원래 파일이 깨지지 않습니다. 읽을 수 없는 파일은 `*.corrupt-<시각>`으로 옮겨 두고 빈 상태로 시작합니다.
- 기록을 초기화하려면 관리자 화면의 **기록 전체 삭제**를 씁니다(`records.json.bak-<시각>` 백업이 남음).
